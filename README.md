# Example Hugo site for fanfiction

Fork this and make it your own!  You'll need to install [Hugo](https://gohugo.io/installation/) and [Pandoc](https://pandoc.org/installing.html).

Use `hugo serve` to preview locally.  When you're happy with your changes, run `hugo build` to (re)generate your site under `docs/`.  Commit, push, and set up GitHub Pages pointing at `docs/`.

Full tutorial to follow.
